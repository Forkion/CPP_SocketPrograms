# Тестовое задание C++

## CPP_SocketPrograms

Две программы и динамическая библиотека для обработки строк с взаимодействием через сокет.

- **Динамическая библиотека: C++**: сортировка, подсчет суммы и проверка кратности
- **Программа №1**: Многопоточное консольное приложение (клиент)
- **Программа №2**: Серверное приложение для проверки данных

## Возможности

### Библиотека

- Сортировка элементов строки по убыванию с заменой четных на "КВ"
- Подсчет суммы всех числовых элементов строки
- Проверка кратности 32 суммы элементов строки

### Программа №1 (Клиент)

- Ввод строки из цифр (не более 64 символов)
- Два потока: ввод/сортировка и обработка/отправка
- Синхронизация через mutex и condition_variable
- Общий буфер для обмена данными между потоками
- Отправка данных в Программу №2 через TCP сокеты
- Автоматическое переподключение при потере связи

### Программа №2 (Сервер)

- Ожидание подключения от Программы №1
- Прием данных через TCP сокеты
- Проверка данных через функцию 3 из библиотеки
- Вывод результата проверки в консоль


## Требования
- Ubuntu 24.04+
- Компилятор gcc с поддержкой C++20

## Сборка и запуск
### Makefile
Поддерживаются следующие цели makefile:

| Цель | Описание |
|------|----------|
| `make` | Сборка динамической библиотеки и обоих программ |
| `make lib` | Сборка динамической библиотеки |
| `make app1` | Сборка программы №1 (клиент) |
| `make app2` | Сборка программы №2 (сервер) |
| `make run_app1` | Запуск программы №1 (клиент) |
| `make run_app2` | Запуск программы №2 (сервер) |
| `make test` | Сборка и запуск unit-тестов |
| `make valgrind_test` | Запуск тестов с проверкой утечек памяти (Valgrind) |
| `make gcov_report` | Генерация HTML-отчёта о покрытии кода тестами |
| `make dvi` | Генерация HTML-документации проекта (Doxygen) |
| `make dist` | Создание архива `.tar.gz` со всеми исходниками |
| `make clang` | Автоматическое форматирование кода по стилю Google |
| `make check_clang` | Проверка соответствия кода стилю Google |
| `make stop` |	Остановка всех запущенных процессов |
| `make stop_app1` | Остановка процесса программы №1 |
| `make stop_app2` | Остановка процесса программы №2 |
| `make clean` | Удаление всех собранных файлов и временных данных |

### Сборка проекта

Для сборки из директории CPP_SocketPrograms/

```bash
# Сборка библиотеки, приложений
make

# Запуск программы 1
make run_app1

# Запуск программы 2
make run_app2

# Сборка и запуск тестов
make test

# Проверка на утечки памяти
make valgrind_test

# Генерация отчёта о покрытии кода
make gcov_report

# Генерация документации
make dvi

# Создание дистрибутивного архива
make dist

# Остановить все процессы на порту 32929 (через который подключаются программы)
make stop

# Очистить
make clean
```
